## 1. Опис завдання
Розробити консольну програму на Java 21 для обробки даних готелю. Програма зчитує записи з CSV-файлу, виконує валідацію (перевірка на порожні значення, коректність числових форматів та відсутність від'ємних значень) і обчислює статистичні показники: загальну кількість ночей, загальний виторг та тривалість найдовшого проживання. Результати форматуються та виводяться в консоль і текстовий файл. Реалізовано підтримку параметрів командного рядка `--help` та `--version`.

## 2. Інфраструктура проєкту
- **Система збірки та управління залежностями:** Maven (використовується Maven Wrapper `mvnw` для кросплатформності).
- **Фреймворк для тестування:** JUnit 5.
- **Статичний аналіз коду:** SpotBugs (налаштований на автоматичний запуск під час фази `verify`).
- **Документація:** Javadoc.
- **CI/CD:** GitHub Actions (матрична збірка для Ubuntu, Windows, macOS).

## 4. Автоматизація та Артефакти (CI/CD)
Процес безперервної інтеграції налаштовано у файлі `.github/workflows/ci.yml`. При кожному пуші в гілку `main` або створенні Pull Request сервери GitHub автоматично запускають тести та статичний аналізатор на трьох операційних системах.

- **Успішний запуск Actions (CI Build):** https://github.com/LevytskyOleg/kzp-lab01-levytskiy/actions/runs/35621725730
- Готові виконувані `.jar` файли автоматично генеруються та доступні для завантаження в секції **Artifacts** за посиланням вище.

## 5. Декларація академічної доброчесності та використання ШІ
Під час виконання цієї лабораторної роботи штучний інтелект використовувався як асистент-ментор для:
- Налаштування інфраструктури проєкту (пояснення структури `pom.xml`, фаз Maven та генерації Wrapper).
- Опанування Git-робочого процесу (створення гілок, комітів, прив'язка Pull Requests до Issues).
- Аналізу та виправлення зауважень статичного аналізатора SpotBugs (зокрема, усунення попередження `NP_NULL_ON_SOME_PATH_FROM_RETURN_VALUE`).
- Написання конфігураційного сценарію `ci.yml` для автоматизації в GitHub Actions.
- Оформлення професійної документації за допомогою Javadoc.
  Увесь програмний код, згенерований або змінений за допомогою ШІ, був проаналізований, зрозумілий та інтегрований у проєкт самостійно.
