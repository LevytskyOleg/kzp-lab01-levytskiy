# Обробка даних готелю (Варіант 14)

## Призначення
Програма читає записи про проживання гостей з `data/input.csv`, перевіряє їх на коректність, обчислює статистичні показники та формує звіт у консоль і текстовий файл.

## Формат входу
Один запис розміщують у рядку, поля розділяють крапкою з комою. Файл кодують у UTF-8.
Формат запису: `номер кімнати (int); ім'я гостя (String);  кількість ночей (int); ціна за ніч (double); категорія номера (String)`.

## Нові компоненти у версії 5.0.0 (Лабораторна робота № 5)

У цій версії застосунок доповнено типобезпечним сховищем у пам'яті, системою обробки винятків зі збереженням першопричини та модулем універсального рефлексивного CSV-експорту/імпорту в кодуванні UTF-8[cite: 5]:

* **`Repository<T>`** — параметризоване сховище об'єктів без використання `raw types`[cite: 7, 12]. Підтримує додавання елементів (`add`), отримання незмінного знімка (`all` через `List.copyOf`) та пошук за предикатом (`find(Predicate<? super T>)`)[cite: 7, 27].
* **`DataStorageException`** — власний `checked`-виняток предметної області, який обгортає технічні помилки вводу-виводу (`IOException`), форматування даних або рефлексії зі збереженням першопричини (`cause`)[cite: 6, 10].
* **`@CsvColumn`** — анотація з `@Retention(RUNTIME)` та `@Target(FIELD)` для декларативного задання заголовків CSV-стовпців над полями класу[cite: 7, 12].
* **`CsvExporter`** — універсальний рефлексивний експортер, який не прив'язаний до конкретного домену[cite: 9, 12]. Зчитує поля з `@CsvColumn`, сортує їх за Java-іменами для детермінованого порядку заголовків, екранує коми, подвійні лапки й перенесення рядків та записує файл через `Path` і `Files` із явним `StandardCharsets.UTF_8`[cite: 6, 8, 12].
* **`CsvParser`** — документний парсер CSV на базі машини станів, який коректно обробляє поля в лапках із комами та перенесеннями рядків (multiline) без розриву записів[cite: 9, 15, 29].
* **`BookingRecord` (Варіант 14 — Готель)** — незмінний запис бронювання з полями `room`, `guest`, `checkIn`, `checkOut`, `rate` (заголовки CSV: `заїзд,виїзд,гість,тариф,номер`) та методами відновлення з CSV (`fromCsv`, `fromFields`) для перевірки `round-trip`[cite: 14, 28].
