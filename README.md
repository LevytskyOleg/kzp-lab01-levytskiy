# Обробка даних готелю (Варіант 14)

## Призначення
Програма читає записи про проживання гостей з `data/input.csv`, перевіряє їх на коректність, обчислює статистичні показники та формує звіт у консоль і текстовий файл.

## Формат входу
Один запис розміщують у рядку, поля розділяють крапкою з комою. Файл кодують у UTF-8.
Формат запису: `ім'я гостя (String); номер кімнати (int); кількість ночей (int); ціна за ніч (double); категорія номера (String)`.

## Збірка та запуск
\`\`\`text
mvnw.cmd verify
mvnw.cmd package
java -jar target/lab01-1.0.0.jar
\`\`\`
На macOS та Ubuntu замість `mvnw.cmd` використовуйте `./mvnw`[cite: 1].
