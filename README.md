# Обробка даних готелю (Варіант 14)

## Призначення
Програма читає записи про проживання гостей з `data/input.csv`, перевіряє їх на коректність, обчислює статистичні показники та формує звіт у консоль і текстовий файл.

## Формат входу
Один запис розміщують у рядку, поля розділяють крапкою з комою. Файл кодують у UTF-8.
Формат запису: `номер кімнати (int); ім'я гостя (String);  кількість ночей (int); ціна за ніч (double); категорія номера (String)`.

## Збірка та запуск
\`\`\`text
mvnw.cmd verify
mvnw.cmd package
java -jar target/lab01-1.0.0.jar
\`\`\`
На macOS та Ubuntu замість `mvnw.cmd` використовуйте `./mvnw`[cite: 1].

## Оновлення в Лабораторній №2 (Варіант 14)
Проєкт переведено на використання об'єктно-орієнтованого підходу. Створено незмінний клас-сутність `Booking` для представлення записів готелю. Валідація даних (перевірка на від'ємні значення та порожні рядки) тепер повністю інкапсульована в конструкторі. Читання з CSV відбувається через фабричний метод `fromCsv`. Для зберігання фінальної статистики використовується `record NightsRate`.
